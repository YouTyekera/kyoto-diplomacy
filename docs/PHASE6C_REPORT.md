## 1. 中立補給拠点とクリック範囲

`board-camera.ts` に表示幅と全域fit幅の比を用いた滑らかな補間を追加した。比率0.68以下は従来サイズ、0.88以上は70%、間はsmoothstep。中立・未所有の円だけ半径6から4.2、線幅1.6から1.12へ変化する。所有済み拠点・Army・選択リングは独立し、軍の有無で円の寸法を変更しない。

SC本体の外側に、透明なhit targetを独立配置した。半径は従来の6より大きい8.5以上、画面上の半径も10px以上。小さな可視円の外側をクリックして地域を選べる。選択の細いリング・キーボードfocus・Army前面の描画順を維持した。地理アンカーは変更していない。

## 2. 用語と日本語

HUD・ロビー・参加者一覧・インスペクタ・冬の操作・所有更新・対局結果・通知・ヘルプを「補給拠点」に統一した。「敵の初期補給拠点」「補給拠点 +N」も統一。古い検証モジュール由来の文面は、`playerMessage` でUIに表示するときだけ翻訳し、coreの意味やデータを変更しない。

「マップ上の装備」「継続中の封鎖」「前回の行軍結果」「全域を表示」「選択地域を拡大」へ整理した。装備イベントの取得説明は指定どおり「撤退処理が終わった時点で、その地域にいる軍の勢力が装備を獲得します。」とした。所持装備がない場合の説明にも同文を使う。地図エディタの行政区fitは従来どおり「選択区を拡大」で、プレイヤー用ボタンとは区別した。

README・PLAYTESTINGも現在のプレイヤー用語に合わせた。JSON・TypeScript・telemetryの内部識別子は変更していない。

## 3. 勝利条件パネル

Top HUDの音量設定の隣に「勝利条件」を追加した。backdropとmodalを使わないpopoverで、外側の地図操作はそのまま利用できる。「閉じる」で畳める。

オンラインPublicGameView、ローカルGameSessionStateの `victoryTargetSC`、`requiredRivalInitialSupplyCentersForInstantWin`、`maxYears` を直接参照する。目標数や年数を固定値で説明しない。補給拠点目標と敵の初期拠点の追加条件、冬の新規脱落による終了、規定年数、0拠点または拠点以外の支配地域0による脱落、最多・同数の共同勝利を表示する。脱落の0条件と同数処理は既存の固定ルールで、変更可能な別設定を作っていない。

単体テストで19拠点・敵4拠点・7年という非既定値を確認し、E2Eでは3人の23拠点・敵2拠点・変更した2年を確認した。実ブラウザでも現在の5年設定が表示された。開始後の設定固定・勝利判定には手を加えていない。

## 4. カメラ

プレイヤー用の最大表示幅を「全域を表示」のfit幅×1.04へ制限した。＋/−・ホイール・resize・初期fit・全体復帰に同じ上限を適用する。resize時はキャンバス縦横比で再計算する。パンは既存操作を維持し、盤面を完全に画面外へ追い出す位置を制限する。

イベントfocusと選択地域拡大は現在よりズームアウトしない。行政区フィルター中はその区、全行政区表示で地域選択があればその地域へ寄せる。「全体に戻す」は全拠点・現在の軍を中心にしたPhase 6Bの作戦表示を維持する。全域表示では無人の外周も残す。

画面付きChromiumで1920×1080・1280×720を確認した。全域で小さな中立拠点を円の外側から選択し、細いリング・地名・山地背景を確認した。勝利条件を開いたまま自軍「桃園」を左クリックし、「小川」へ右クリックした。両解像度でサーバーの本人用Move、矢印1本、command dock「移動 → 小川」を確認した。記録に秘密tokenを含めていない。
