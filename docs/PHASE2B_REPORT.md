## 2. controller / SC更新の仕様

移動・撤退裁定そのものは従来のrules-coreを維持し、game-coreで盤面へ反映します。

- 合法なMove成功時に移動先のcontrollerを軍の所有勢力へ更新します。出発元のcontrollerは維持します。失敗命令とRetreatで支配を変更しません。
- 春・秋とも、移動と撤退の終了後にSC Update画面を経由します。その時点のcontrollerをSC所有者へ反映します。nullならSC所有もnullです。
- SC更新前後を画面に表示し、変化したSCは更新後も一覧で確認できます。軍位置・支配・SC所有を分離しています。
- 京都御苑は地域・controller・SC・軍・隣接ノードとして登録しません。既存のplayableGeometryと最終隣接を使います。

年間進行の初期盤面は、ユーザーが確認した現在Previewのコピーです。元行政区を使った正式なゲーム初期支配や無所属区抽選は追加していません。

## 3. Build / Disband仕様

初期地点は、開始時の静的地図にその勢力のstartingUnitが置かれていた地域集合です。開始後に軍が移動しても変えず、homeWardIdは参照しません。Previewだけに追加した軍の位置は初期地点へ追加しません。

増員上限はmax(0, SC数−軍数)。空いている初期地点・SC・現在のSC所有者が自勢力という全条件を満たす地点のみ選べます。armyだけを作成し、増員枠は使い切る義務を設けません。

軍数がSC数を超える勢力は差分だけ解散します。軍を手動選択し、全勢力の操作を一括確定します。不足・過剰・重複・不正な対象や増員先はエラーとなり、冬に留まります。解散対象を自動選択しません。画面にはSC/軍/非SC支配の数、増員可能数・地点、必要解散数を表示します。

## 4. 勝利 / 脱落 / 最終年の実装

順序は第1年春Orders → Retreats → 春SC Update → 秋Orders → Retreats → 秋SC Update → 冬Adjustments → 冬後の脱落/年末判定 → 次年春です。各段階をボタンで確認できます。

春秋のSC更新直後、参加勢力が15SC以上なら即停止・勝利表示します。複数勢力が同時に条件を満たす場合は候補を表示し、独自の優先順で選びません。

冬清算後にSCゼロまたは支配する非SC地域ゼロなら脱落し、その年を最終年として「この年で終了対象」を表示します。脱落理由と最終年を保持し、次年へ進めません。この終了時の勝者/順位は未確定のままです。

規定年数は初期値null（画面は空欄）です。ユーザーが検証用に整数を設定でき、年数終了時には最多SCを判定します。同点なら勝者を確定せず候補とTODOを表示します。未指定の年数を独断で固定していません。

参加勢力は開始画面で明示選択します。初期チェックは現在軍の所有勢力で、軍の所有勢力は全て参加指定が必要です。参加していない行政区をゼロSCの脱落候補に含めません。この指定はローカル検証の対象選択であり、正式なプレイヤー割当規則は追加していません。

## 5. ピン型ユニット表示の仕様

編集・Preview・Sandbox・年間進行を、独自のteardrop SVGへ統一しました。所有勢力色と内部の白い三角記号を使い、他作品の画像を使いません。矩形や「Aを丸で囲んだだけ」の表示を廃止しました。

displayAnchor基準とsemantic zoomを維持します。幅はclamp(10, 22, 12×倍率^0.35) px、高さは幅の18.75/14。SC同居時は背後の円をピンより広く表示します。長いleader lineはありません。hover/選択で地域とマーカーを強調し、命令入力中は命令・支援対象・移動先も確認できます。

## 6. 御苑表示の改善内容

既存GeoJSONのポリゴン全体を濃い緑（#354640、不透明度0.6）で塗り、濃い境界線と薄いハッチングを重ねました。元ポリゴンに沿って表示し、別の矩形で近似していません。Phase 2Aの御苑境界・元KML・playableGeometry生成は変更していません。

読み込み中の境界が標準案に一致しない/存在しない場合は軽い注意を表示します。ユーザー編集済みの場合も注意が出ますが、設定を勝手に置き換えません。専用ボタンで明示的に読み込めます。年間進行中の注意・描画は開始時に固定した地図を参照します。

## 9. ブラウザで確認する手順

1. リポジトリ直下で `npm.cmd run dev`。http://127.0.0.1:5173/ を開きます。すでに起動していれば再読み込みします。
2. 地図の採用・SC・初期軍を設定してPreviewを再生成します。架空サンプルでも試せます。
3. 「年間進行（ローカル）」→参加勢力を確認→「現在のPreviewから開始」。必要なら規定年数を明示指定します。
4. 全軍に合法な命令を入力して「移動を裁定」。地図の支配色と軍を確認します。
5. 撤退があれば各軍の入力を行い同時解決。「次へ進む」でSC更新画面を確認し、再度進めて反映します。
6. 秋も裁定とSC更新を行い、冬に空いた初期地点SCへBuild、必要数の軍へDisbandを指定して確定します。
7. 年末判定で、次年春への進行または最終年の停止を確認します。resetで起動時へ戻せます。
8. 上京区を拡大し、ピン・SC円と御苑の濃色領域を確認します。古い御苑境界は注意を確認し、必要なら編集モードで標準案を読み込んで保存します。

開始時地図と年間状態は元Preview/設定と独立しています。モード切替では保持しますが、再読み込み・タブ終了・データセット切替で年間状態を失います。今回ゲーム状態の保存/読込は追加していません。設定とPreviewの従来の保存は引き続き利用できます。
