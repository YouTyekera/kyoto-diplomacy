## 2. UI改善内容

通常表示のマーカーをdisplayAnchor中心へ固定しました。衝突回避で他地域へ押し出さず、長いleader lineも描画しません。選択マーカーは最後に描画して強調します。狭い地域同士では重なりが残るため、hover/選択で輪郭と詳細を確認します。

Armyは所有勢力色の小型矩形と独自の線記号です。常時の勢力名入り盾を廃止し、編集・Preview・Sandboxで表示を統一しました。SCは明るい内部・濃い輪郭の円と、SC所有勢力色の内側リングです。中立でも円を表示します。地域のcontroller色とは別です。ArmyとSCの同居時は同じ中心の背後にSC円を広げ、両方を表示します。

表示倍率 `z = 1000 / viewBox幅` に対し、Army幅は `clamp(10, 22, 12 × z^0.35)` px、縦は幅の12/14です。SC半径は単独時にArmy幅の6/14、同居時に11/14です。地域/勢力ラベルは倍率4以上またはhover/選択で表示します。これらはUIの技術調整値で、ゲームルールではありません。

Move命令は青の実線矢印、Supportは茶の破線矢印です。命令一覧と裁定理由にも移動先・支援対象を表示します。

## 5. 実装したDiplomacyルール

- Hold / Move / Support Hold / Support Move。移動・支援の合法性は最終隣接で検証。
- 他勢力への支援、支援命令と対象実命令の一致判定。
- 攻撃/防御/阻止の強さ、有効支援、支援カットと支援先からの攻撃の例外、排除された支援軍の失効。
- 等強度バウンス、スタンドオフ、head-to-head、成功する移動連鎖、3軍以上の循環移動。
- 自己排除禁止、守備勢力の支援による自軍排除禁止、排除元の記録。
- head-to-headで排除された攻撃と、別方向から排除された攻撃の影響の区別。

単発の強さ比較で決めず、移動と支援の依存条件を整合させます。結果は各命令のsuccess/fail・ReasonCode・攻撃/防御/阻止の数値・有効支援、全体のカット支援・スタンドオフ・排除軍・攻撃元・合法撤退先を保持します。日本語説明は別モジュールです。

不存在/重複ユニット・単一地域の重複配置・不正な最終隣接・不存在/重複/未入力命令・非隣接・自己参照・不正な支援先・不存在/除外/侵入不能地域をエラーとして扱い、不正命令をHoldへ変えません。

## 6. Retreatルール

最終隣接から候補を計算し、移動後の占有地域・排除した軍の攻撃元・同移動のスタンドオフ・除外/侵入不能地域を除外します。撤退入力は合法な撤退または解散です。合法性は同時解決時にも再確認します。

同じ地域へ撤退する軍は全て解散し、合法な撤退先がない軍も解散します。合法な候補がある軍の未入力はエラーで、解散を黙って補いません。冬のDisbandは実装していません。

Sandboxでは選択軍の入力だけを表示します。他の軍の入力先を、解決前の地図・矢印・一覧へ渡しません。同一ブラウザで視点を切り替える検証用で、認証付きのオンライン秘密保持は未実装です。「撤退フェイズ中は交渉禁止」を表示します。

## 7. Rules Sandboxの使い方

1. 地域を採用し、Game Previewへユニットを配置します。静的初期配置を使うならPreviewを再生成します。
2. 「ルールサンドボックス」で現在Previewのコピーを開きます。
3. ユニットと命令種別を選び、合法な移動先・支援対象を指定します。変更時に登録され、Holdだけの場合は「この命令を確定」で登録できます。
4. 一覧・矢印を確認し、全軍分を入力して「裁定」。明示的な「未入力をHoldにする」補助も利用できます。
5. 盤面と裁定理由を確認します。排除があれば各軍の撤退/解散を入力し、「撤退を同時解決」を押します。
6. 「次の命令を試す」で現在の軍から続けて検証できます。「初期Previewへリセット」で起動時へ戻します。

controller・SC所有者・年・季節は変わりません。Sandboxの裁定は元のPreview・静的設定を変更/保存しません。

## 10. ブラウザで確認する手順

1. リポジトリ直下で `npm.cmd run dev`。http://127.0.0.1:5173/ を開きます。すでに起動していれば再読み込みします。
2. 上京区を選択して拡大し、必要なら「御苑のゲーム用境界案を読み込む」。滋野の下端まで延びる斜線と差し引き後の2部分を確認します。
3. 「架空サンプルで確認」でも操作できます。いくつかの地域へSC・初期軍を設定し、Previewを再生成します。
4. 全体表示・拡大・hover・選択を試し、小型軍と円形SC、地域との位置関係を確認します。
5. Sandboxで隣接Moveと支援を入力します。対象軍のMove先とSupport Move先を合わせ、「裁定」を押します。
6. 排除が起きた場合は撤退先を入力し、解決前の地図へ表示されないことと、同時解決後の配置を確認します。
7. resetとPreviewへの復帰を試し、元Previewのユニット・支配・SC所有が維持されることを確認します。
8. 保存する地図編集は設定JSONで保存してください。サーバー停止は起動ターミナルのCtrl + Cです。

詳しい起動・インストール・復旧・Sandbox操作は [README](../README.md) を参照してください。
